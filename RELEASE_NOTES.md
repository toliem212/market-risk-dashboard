# Release Candidate

Bản này hợp nhất các lượt phát triển trước thành một project hoàn chỉnh để chạy cục bộ hoặc đưa lên GitHub/Streamlit Community Cloud.

Các thành phần đã hợp nhất gồm dashboard điều hành, bản đồ rủi ro, báo cáo ngày, FX, TPCP, liên ngân hàng, funding pressure, lãi suất huy động, cảnh báo, exception workflow, historical stress, VaR/ES, backtesting, market-factor attribution, data quality và các phân hệ nhập liệu nghiệp vụ.

Tên ứng viên trên giao diện và báo cáo: **Tô Thanh Liêm**.
