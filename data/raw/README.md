# Dữ liệu đầu vào

Ứng dụng mặc định đọc hai file:

- `usd_vnd_ohlc_daily.xlsx`
- `vn_money_market_funding_rates.xlsx`

Dữ liệu đường cong lợi suất TPCP là tùy chọn và có thể đặt dưới một trong hai tên:

- `vn_gov_bond_yield_curve.xlsx`
- `vn_gov_bond_yield_curve.csv`

Trước khi đưa repository sang chế độ công khai, cần tự xác nhận quyền tái phân phối đối với các file dữ liệu nguồn. Dashboard không tự suy đoán nguồn hay giấy phép của dữ liệu.
